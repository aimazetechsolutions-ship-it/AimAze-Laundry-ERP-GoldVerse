# AimAze Laundry ERP Design System

Phase 5 introduces a reusable SaaS design layer for backend, portal, and reports.

## Tokens

- Primary: Aqua Blue `#2bbbd3`
- Secondary: Deep Blue `#12456f`
- Accent: Orange `#f28c28`
- Success: Soft Green `#40b883`
- Warning: Amber `#f6b43f`
- Danger: Soft Red `#ef6b6b`
- Background: Light Gray `#f6f9fb`

## Components

- KPI cards use `.aimaze-kpi-card` and `.alm-kpi-card`.
- Premium dashboard shells use `.aimaze-dashboard-shell`.
- POS/counter screens use `.aimaze-pos-shell`.
- Portal cards use `.aimaze-portal-card`.
- Kanban cards use `.aimaze-kanban-card`.
- Status labels use `.aimaze-badge`.
- Timeline stages use `.aimaze-timeline` and `.aimaze-timeline-step`.

Use colors to signal status and urgency, not decoration.
