# Responsive Guide

Phase 5 focuses on tablet and mobile ergonomics while keeping Odoo backend compatibility.

## Breakpoints

- Desktop: multi-column dashboard and kanban.
- Tablet: two-column KPI grid and wider action buttons.
- Mobile: single-column KPI grid, stacked actions, and taller touch targets.

Priority screens are Quick Counter Order, Driver Jobs, Garment Tracking, Executive Dashboard, and portal order tracking.
