# Branding Guide

Product name: **AimAze Laundry ERP**

## Visual Direction

The interface should feel premium, clean, GCC-ready, and operational. Avoid generic Odoo-only presentation by using AimAze colors, branded report headers, and consistent KPI/status language.

## Usage

- Aqua Blue for primary action and brand accent.
- Deep Blue for titles and report headings.
- Orange/Amber for warning and urgency states.
- Soft Red for failed, delayed, lost, or urgent issues.
- Soft Green for delivered, paid, ready, and successful outcomes.
