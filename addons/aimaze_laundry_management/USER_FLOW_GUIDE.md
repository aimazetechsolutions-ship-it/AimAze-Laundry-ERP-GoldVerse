# User Flow Guide

## Walk-in Order

1. Open **AimAze Laundry ERP > Orders > Quick Order**.
2. Select customer or create a walk-in customer.
3. Select branch, service type, priority, pickup/delivery requirements.
4. Add garment lines.
5. Confirm order.
6. Register advance payment if received.
7. Move the order through received, washing, ironing, QC, packing, ready, delivery.
8. Create invoice.
9. Register final payment.
10. Print receipt or garment tags.

## Corporate Order

1. Create a contract under **Customers > Contracts**.
2. Link contract to orders.
3. Apply negotiated rate card manually through service prices.
4. Generate monthly invoice from the contract.

## Pickup and Delivery

Use job type:

- Pickup
- Delivery
- Pickup and Delivery

Driver proof and receiver details can be uploaded on the job.
